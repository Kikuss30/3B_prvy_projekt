PHP - Hypertext Preprocessor je open-source 
skriptovací jazyk bežiaci na strane servera.

Architektúra Klient-Server: kód sa vykoná na serveri
a klientovi(priehladaču) sa odošle už len vygenerovaný a čistý HTML,
CSS alebo JSON výstup.

Jazyk PHP- nebude pracovať sám na počítači, musíme 
spustiť MAMP lokálny server,

Tvorba dynamických webových aplikácií, API rozhraní,
komunikácia s databázami a spracovanie formulárov

PHP syntax - <?php a ?> ukončenie bodkočiarkou ;

Výstup - Echo/Print, echo je rýchlejšie
Premenné - znak dolára a musí začínať písmenom
PHP je dynamický typovaný jazyk, typ premennej určí samo podla 
priradenej hodnoty
Dátové typy - zákl. String (text) Integer (čislo) Float (des. číslo) Boolean (Pravda/Nepravda)
znak . - je na spájanie textu s premennou

Práca s reťazcami(Strings): text v php vieme nielen spájať ale aj upravovať pomocou stoviek zabudovaných funkcií (napr. zadanie dĺžky, vyhľadávanie podreťazca,nahradzovanie slov)
čísla a matematika: Okrem základných operácií ponúka PHP funkcie pre zaokrúhľovanie(round()),
generovanie náhodných čísel(rand()) alebo hľadanie min/max hodnôt
Pretypovanie: Proces, kedy explicitne povieme programu, aby zmenil dátový typ premennej

Konštanty- Indentifikátory pre hodnoty, ktoré sa na rozdiel od premenných počas behu skriptu nesmú a nedajú meniť, Ideálne pre heslá a fixné nastavenia.
Operátory - Nástroje na manipuláciu s dátami - aritmetické (matika) priraďovacie(=+), porovnávacie(===) a logické
